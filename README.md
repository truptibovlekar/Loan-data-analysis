#  Loan Portfolio Data Analysis

## Description
This project focuses on performing exploratory data analysis (EDA) on a real-world loan dataset to identify key trends in borrower behavior, credit risk, income levels, and loan performance. The goal is to extract actionable insights that could assist financial institutions in assessing risk and understanding customer profiles more effectively.



##  Objectives
- Understand how borrower attributes such as income, credit score, job tenure, and home ownership relate to financial health and repayment capacity.
- Analyze patterns and correlations across variables like loan amount, monthly debt, credit problems, and open accounts.
- Visualize data distributions and trends to support data-driven decision-making in lending.

---

## Tools & Technologies Used
- **Python**
- **pandas** – data cleaning, filtering, and grouping
- **seaborn** – statistical data visualization


##  Key Features
- Cleaned and prepared a structured loan dataset for analysis
- Identified correlations between income, debt, credit problems, and loan performance
- Summarized insights to highlight risk profiles and lending behavior patterns


## Key Insights
- Income and credit score trends vary across loan purpose, job stability, and home ownership
- Higher monthly debt and more credit problems tend to be associated with larger loan balances
- Visual trends help in segmenting borrowers based on financial health and creditworthiness


##  Project Files
- `Loan_Data_Analysis_Project.ipynb` – the main analysis notebook
- `Loan_dataset.csv` – dataset used for the project
- `README.md` – project overview and documentation


##  How to Use
1. Clone or download this repository
2. Open the notebook in Jupyter Notebook or JupyterLab
3. Make sure the dataset (`Loan_dataset.csv`) is in the same folder
4. Run the notebook to see the analysis and visual insights
